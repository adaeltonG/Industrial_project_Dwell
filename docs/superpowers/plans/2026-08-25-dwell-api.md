# Dwell API Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a PostgreSQL-backed REST API for the existing Dwell marketplace frontend.

**Architecture:** A standalone TypeScript Express application lives in `api`, with feature-focused routers and services. Prisma owns a normalized PostgreSQL schema for users, vendors, categories, products, and saved products; HTTP validation, authentication, and error translation remain at the API boundary.

**Tech Stack:** Node.js, TypeScript, Express, PostgreSQL, Prisma, Zod, JWT, Vitest, Supertest

## Global Constraints

- Backend code lives under `api`.
- PostgreSQL is the only database provider.
- The relational schema must satisfy third normal form.
- Resources use REST-style routes under `/api/v1`.
- Existing frontend files and static prototype behavior remain unchanged.
